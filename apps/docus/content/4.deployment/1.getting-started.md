This guide covers deploying the Turbo Nuxt Starter monorepo to production using GCP Cloud Run.

## Architecture Overview

```
┌─────────────────────────────────────────────────────────────┐
│                    Google Cloud Platform                     │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  Artifact Registry          Cloud Run Services              │
│  ┌──────────────┐          ┌─────────────────────────────┐ │
│  │ turbo-repo   │          │                             │ │
│  │ ├─ api      ─┼──────────┼─► turbo-api    (Port 3002)  │ │
│  │ ├─ nuxt     ─┼──────────┼─► turbo-nuxt   (Port 3001)  │ │
│  │ └─ docus    ─┼──────────┼─► turbo-docus  (Port 80)    │ │
│  └──────────────┘          └─────────────────────────────┘ │
│                                                              │
│  Secret Manager             GitHub Actions                   │
│  ┌──────────────┐          ┌─────────────────────────────┐ │
│  │ database-url │          │ Workload Identity Federation │ │
│  │ supabase-*   │          │ (keyless authentication)     │ │
│  └──────────────┘          └─────────────────────────────┘ │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

## Why GCP Cloud Run?

| Feature | Benefit |
|---------|---------|
| **Scale to zero** | No charges when idle |
| **Auto-scaling** | Handles traffic spikes automatically |
| **Managed SSL** | Free HTTPS certificates |
| **Container-based** | Use existing Docker images |
| **Global CDN** | Low latency worldwide |
| **Simple pricing** | Pay per request/CPU |

## Deployment Steps

::steps

### 1. Set up GCP Infrastructure

Use Terraform to create the required GCP resources:

- Artifact Registry for container images
- Cloud Run services for each app
- Secret Manager for sensitive configuration
- IAM roles for GitHub Actions

[GCP Cloud Run Guide →](/deployment/gcp-cloud-run)

### 2. Configure GitHub Actions

Set up CI/CD pipelines for automated deployments:

- Build and push Docker images
- Deploy to Cloud Run on push to main
- Workload Identity Federation (no service account keys)

[CI/CD Guide →](/deployment/ci-cd)

### 3. Configure Environment Variables

Set up secrets and environment variables:

- Database connection string
- Supabase credentials
- API configuration

[Environment Variables →](/deployment/environment-variables)

::

## Prerequisites

Before deploying, ensure you have:

- [ ] GCP account with billing enabled
- [ ] `gcloud` CLI installed and authenticated
- [ ] Terraform >= 1.5.0 installed
- [ ] GitHub repository with Actions enabled

## Cost Estimate

Cloud Run pricing for a typical starter project:

| Resource | Monthly Cost |
|----------|-------------|
| **API service** | ~$5-20 (depending on traffic) |
| **Nuxt service** | ~$5-20 |
| **Docus service** | ~$0-5 (low traffic) |
| **Artifact Registry** | ~$1-5 (storage) |
| **Secret Manager** | ~$0.50 (10k requests free) |
| **Total** | **~$12-50/month** |

Scale to zero means you only pay when services are actively handling requests.

## Quick Start

For those who want to deploy quickly:

```bash [Terminal]
# Navigate to terraform directory
cd infra/terraform

# Copy and configure variables
cp terraform.tfvars.example terraform.tfvars
# Edit terraform.tfvars with your project ID

# Initialize and apply
terraform init
terraform apply

# Push initial images
gcloud auth configure-docker europe-west1-docker.pkg.dev
docker build -f apps/api/Dockerfile -t europe-west1-docker.pkg.dev/PROJECT/turbo-repo/api:latest .
docker push europe-west1-docker.pkg.dev/PROJECT/turbo-repo/api:latest
```

See the detailed guides for complete instructions.
