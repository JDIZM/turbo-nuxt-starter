The project includes Docker Compose configurations for both development and production environments.

## Development Setup

The `docker-compose.dev.yml` file provides a development environment with:

- PostgreSQL database with health checks
- Express API with hot reload
- Nuxt frontend with HMR (Hot Module Replacement)
- Volume mounts for live code updates

### Starting the Environment

```bash [Terminal]
# Start all services
pnpm docker:dev

# Or start in detached mode
pnpm docker:dev:detach

# View logs
pnpm docker:logs
```

### What's Running

| Container | Port | Description |
|-----------|------|-------------|
| `turbo-postgres-dev` | 54322 | PostgreSQL 16 database |
| `turbo-api-dev` | 3002 | Express API with tsx watch |
| `turbo-nuxt-dev` | 3001 | Nuxt with HMR |

## Docker Compose Files

### docker-compose.dev.yml

Development environment with hot reload:

```yaml
services:
  db:
    image: postgres:16-alpine
    ports:
      - "54322:5432"
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U postgres"]

  api:
    build:
      dockerfile: apps/api/Dockerfile.dev
      target: dev
    volumes:
      - ./apps/api/src:/app/apps/api/src:ro
    depends_on:
      db:
        condition: service_healthy

  nuxt:
    build:
      dockerfile: apps/nuxt/Dockerfile.dev
      target: dev
    depends_on:
      - api
```

### docker-compose.db.yml

Standalone database for non-Docker development:

```bash [Terminal]
# Start just the database
pnpm docker:db

# Connect from host machine
psql postgresql://postgres:postgres@localhost:54322/postgres
```

### docker-compose.yml

Production configuration with multi-stage builds:

```bash [Terminal]
# Build and run production containers
pnpm docker:prod
```

## Development Dockerfiles

Each app has a `Dockerfile.dev` optimized for development:

### apps/api/Dockerfile.dev

```dockerfile
FROM node:22-alpine AS base
# ... base setup

FROM base AS pruner
COPY . .
RUN pnpx turbo prune api --docker

FROM base AS dev
COPY --from=pruner /app/out/json/ .
RUN pnpm install --frozen-lockfile
COPY --from=pruner /app/out/full/ .

CMD ["pnpm", "--filter=api", "dev"]
```

Key features:
- Uses `turbo prune` for minimal image size
- Runs `tsx watch` for hot reload
- Volume mounts override source files

### apps/nuxt/Dockerfile.dev

Similar pattern with Nuxt-specific HMR configuration.

## Environment Variables

Development containers use these defaults:

```env
# Database (connects to 'db' container)
DATABASE_URL=postgresql://postgres:postgres@db:5432/postgres

# Supabase (optional - for auth)
SUPABASE_URL=http://host.docker.internal:54321

# API CORS
CORS_ORIGIN=http://localhost:3001,http://localhost:3000

# Logging
LOG_LEVEL=debug
```

## Docker Commands Reference

```bash [Terminal]
# Start development environment
pnpm docker:dev

# Start in background
pnpm docker:dev:detach

# Start only database
pnpm docker:db

# Stop all containers
pnpm docker:down

# View logs
pnpm docker:logs

# Reset database and volumes
pnpm docker:reset

# Production build
pnpm docker:prod
```

## Troubleshooting

### Container won't start

Check logs for specific errors:

```bash [Terminal]
docker compose -f docker-compose.dev.yml logs api
```

### Database connection failed

Ensure the database is healthy:

```bash [Terminal]
docker exec turbo-postgres-dev pg_isready -U postgres
```

### Hot reload not working

Volume mounts require Docker Desktop file sharing. Check Docker settings and ensure your project directory is shared.

### Port already in use

```bash [Terminal]
# Find process using port
lsof -i :3002

# Kill it
kill -9 <PID>
```
