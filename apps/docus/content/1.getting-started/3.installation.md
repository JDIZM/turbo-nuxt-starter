## Prerequisites

Before you begin, ensure you have the following installed:

| Tool | Version | Purpose |
|------|---------|---------|
| **Node.js 22 | JavaScript runtime |
| **pnpm** | >= 10.17 | Package manager |
| **Docker** | Latest | Container runtime |
| **Git** | Latest | Version control |

::prose-note
We recommend using [Corepack](https://nodejs.org/api/corepack.html) to manage pnpm versions. It's included with Node.js 16+.
::

## Quick Start

::steps

### Clone the repository

```bash [Terminal]
git clone https://github.com/JDIZM/turbo-nuxt-starter.git
cd turbo-nuxt-starter
```

### Enable Corepack and install dependencies

```bash [Terminal]
corepack enable
pnpm install
```

### Set up environment variables

```bash [Terminal]
cp .env.example .env
```

Edit `.env` with your configuration. For local development, the defaults work out of the box.

### Start the database

```bash [Terminal]
pnpm docker:db
```

This starts a PostgreSQL container on port 54322.

### Run database migrations

```bash [Terminal]
pnpm --filter=db-schema run db:push
```

### Start all apps in development mode

```bash [Terminal]
pnpm dev
```

::

## Access Points

After starting the development server, you can access:

| Service | URL | Description |
|---------|-----|-------------|
| **Nuxt Frontend** | http://localhost:3001 | Main application |
| **Express API** | http://localhost:3002 | REST API |
| **API Docs** | http://localhost:3002/docs | OpenAPI/Swagger UI |
| **Docus** | http://localhost:3003 | Documentation site |
| **Nitro** | http://localhost:3004 | Nitro server |
| **Storybook** | http://localhost:6006 | Component library |
| **Vite App** | http://localhost:3000 | Vue 3 SPA |

## Alternative: Docker Development

For a fully containerized development environment:

```bash [Terminal]
# Run the setup script
pnpm setup

# Or start Docker manually
pnpm docker:dev
```

This starts all services with hot reload enabled.

## Available Scripts

| Script | Description |
|--------|-------------|
| `pnpm dev` | Start all apps in development mode |
| `pnpm build` | Build all apps for production |
| `pnpm lint` | Run ESLint and fix issues |
| `pnpm lint:check` | Check for linting errors |
| `pnpm format` | Format code with Prettier |
| `pnpm typecheck` | Run TypeScript type checking |
| `pnpm test:unit` | Run unit tests |
| `pnpm docker:dev` | Start Docker development environment |
| `pnpm docker:db` | Start PostgreSQL database |
| `pnpm docker:down` | Stop all Docker containers |
| `pnpm docker:reset` | Reset database and volumes |

## Supabase Setup (Optional)

If you want to use Supabase for authentication:

::steps

### Install Supabase CLI

```bash [Terminal]
brew install supabase/tap/supabase
```

### Start local Supabase

```bash [Terminal]
supabase start
```

### Get credentials

```bash [Terminal]
supabase status
```

Copy the output values to your `.env` file.

::

## Troubleshooting

### Port conflicts

If you see port conflict errors, check that no other services are using ports 3000-3006 or 54322.

```bash [Terminal]
# Check what's using a port (macOS/Linux)
lsof -i :3002
```

### Node version issues

Ensure you're using Node.js 22+:

```bash [Terminal]
node 22.x.x or higher
```

### pnpm version issues

The project uses pnpm 10.17.1. Corepack handles this automatically:

```bash [Terminal]
corepack enable
corepack prepare pnpm@10.17.1 --activate
```

### Docker issues

If Docker containers fail to start:

```bash [Terminal]
# Reset everything
pnpm docker:reset

# Check Docker is running
docker info

# View container logs
pnpm docker:logs
```
