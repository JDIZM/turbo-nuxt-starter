Welcome to **Turbo Nuxt Starter**, a production-ready monorepo template for building full-stack applications with Vue 3 and Node.js.

## What is Turbo Nuxt Starter?

Turbo Nuxt Starter is an opinionated monorepo template that combines:

- **Nuxt 4** - Vue 3 with server-side rendering
- **Express API** - REST API with OpenAPI documentation
- **TypeScript** - Full type safety across the stack
- **Drizzle ORM** - Type-safe database queries
- **Supabase** - Authentication and PostgreSQL database
- **Turborepo** - Incremental builds and caching
- **Docker** - Containerized deployments
- **GCP Cloud Run** - Serverless container hosting

## Tech Stack

| Category | Technology |
|----------|------------|
| **Frontend** | Nuxt 4, Vue 3, Tailwind CSS, DaisyUI |
| **Backend** | Express 4, Node.js 22, pino-http |
| **Database** | PostgreSQL 16, Drizzle ORM, Supabase |
| **Validation** | Zod, zod-to-openapi |
| **Auth** | JWT, Supabase Auth |
| **Build** | Turborepo, pnpm workspaces, Vite |
| **Testing** | Vitest, Testing Library |
| **Docs** | Docus, Storybook |
| **Deploy** | Docker, GCP Cloud Run, Terraform |
| **CI/CD** | GitHub Actions, Renovate |

## Project Structure

```
turbo-nuxt-starter/
├── apps/
│   ├── api/           # Express REST API (Port 3002)
│   ├── nuxt/          # Nuxt 4 frontend (Port 3001)
│   ├── nitro/         # Nitro server (Port 3004)
│   ├── docus/         # Documentation site (Port 3003)
│   ├── storybook/     # Component library (Port 6006)
│   └── vite/          # Vue 3 SPA (Port 3000)
├── packages/
│   ├── api-types/     # Zod schemas with OpenAPI decorators
│   ├── db-schema/     # Drizzle ORM schema and migrations
│   ├── helpers/       # HttpError, apiResponse, utilities
│   ├── logger/        # Pino logger factory
│   ├── ui/            # Vue 3 components with Tailwind
│   ├── eslint-config-custom/
│   ├── tsconfig/
│   └── tailwind-config/
├── infra/
│   └── terraform/     # GCP Cloud Run infrastructure
├── supabase/          # Local Supabase configuration
├── docker-compose.yml # Production Docker setup
├── docker-compose.dev.yml # Development Docker setup
└── docker-compose.db.yml  # PostgreSQL database
```
